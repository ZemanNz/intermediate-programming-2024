# intermediate-programming-2024

Potkáváme se každý čtvrtek od 16:00 do 17:30(18:00).

| Příkaz | Popis |
|-------|-------|
| `git fetch upstream` | Načtení změn z upstream repozitáře |
| `git checkout week18` | Přepnutí na větev `week18` |
| `cd week18` | Změna adresáře na `week18` |
| `git checkout week18` | Přepnutí na větev `week18` |
| `git checkout -b week_18` | Vytvoření a přepnutí na novou větev `week_18` |
| `git push origin week_18` | Odeslání nové větve `week_18` do origin repozitáře |
| `git commit -a -m "aaaa"` | Commit všech změn s komentářem "aaaa" |
| `git push origin week_18` | Odeslání commitů na větev `week_18` v origin repozitáři |


| Příkaz | Popis |
|-------|-------|
| `git branch -d week18` | Smaže lokální větev `week18`. |
| `git push origin --delete week18` | Smaže vzdálenou větev `week18` na serveru origin. |
